Sample input data: a consistent 2,000-order extract of the Olist Brazilian E-Commerce
Public Dataset (Kaggle, CC BY-NC-SA 4.0), with the matching items, payments, reviews,
customers, products, sellers, and up to 15 geolocation points per zip prefix.
Use it to build and try the system without downloading the full dataset (see README.md,
"Quick start with the bundled sample data"). Full-dataset results are in the report.
